The funniest one-line fortune cookie message for a software engineer: your lucky numbers are the six digits of the verification code that just expired. Pure Python standard library, deterministic output.

## Run it

```sh
python3 main.py
```

This writes the single fortune line to `$OUTPUT_DIR/entry.txt` (default `/output`).
